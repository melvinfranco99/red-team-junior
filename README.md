# Red Team Junior · Curso para la entrevista

Curso web gratuito, interactivo y **de cero a la entrevista**, para preparar un puesto **Técnico Junior de Red Team / pentesting**. Cubre los requisitos típicos de la oferta: redes, Linux/Windows, OWASP Top 10, Nmap, Burp Suite, enumeración y fuzzing, inyecciones (SQLi, XSS, SSRF), APIs y JWT, contraseñas/hashes, scripting e IA, seguridad móvil, informes y PoC.

## Contenido

- **19 módulos** en 6 niveles, con analogías, diagramas, tablas y terminales de ejemplo.
- **7 laboratorios interactivos**: analizador HTTP, OWASP Top 10, clasificador de ataques, lectura de fuzzing, constructor de comandos **Nmap**, calculadora **CVSS 3.1** y **simulador de entrevista**.
- **95 preguntas** de test + **examen final** de 30 preguntas aleatorias.
- **Chuleta** de comandos y herramientas + **glosario** de 93 términos con flashcards.
- El progreso se guarda en el navegador (localStorage). Sin dependencias ni build.

## Estructura

```
index.html              SPA estática
assets/css/style.css    estilos (tema claro/oscuro)
assets/js/curso.js      módulos, lecciones y tests
assets/js/datos.js      glosario, herramientas y chuleta
assets/js/labs.js       laboratorios interactivos
assets/js/app.js        navegación, progreso y examen
```
